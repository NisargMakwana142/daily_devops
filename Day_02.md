### sudo & user management
- `sudo` — group with root-level user permissions
- `sudo apt-get update`
- `sudo apt-get upgrade`
- `sudo useradd -m <name>` - create user with home directory
- `sudo useradd -m <name> -s /bin/bash` - create user with bash shell
- `su` — switch/substitute user
